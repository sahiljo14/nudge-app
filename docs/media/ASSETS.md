# Media assets

Drop README graphics and screenshots here.

## Expected files

| File | Purpose | Recommended size |
|---|---|---|
| `banner.png` | Hero banner at the top of the README | 1280 x 400 |
| `logo.svg` | App logo under the banner | 160 x 160 (square) |
| `demo.gif` | 30-60s walkthrough loop | 280 - 360 wide |
| `demo.mp4` | High-quality video (optional) | 720p+ |
| `demo-thumbnail.png` | Click-through thumbnail for the video | 16:9 |
| `why-illustration.png` | Illustration next to "Why Nudge" | square or 4:3 |
| `screen-home.png` | Home screen | 270 x 540 (portrait) |
| `screen-calendar.png` | Calendar screen | 270 x 540 |
| `screen-add.png` | Add task screen | 270 x 540 |
| `screen-ocr.png` | OCR scan screen | 270 x 540 |
| `screen-share.png` | Share intent import | 270 x 540 |
| `screen-profile.png` | Profile screen | 270 x 540 |
| `screen-onboarding.png` | Onboarding (collapsible) | 270 x 540 |
| `screen-voice.png` | Voice input (collapsible) | 270 x 540 |
| `screen-dark.png` | Dark mode (collapsible) | 270 x 540 |
| `parser-demo.gif` | Optional - parser in action | 320 wide |

## Tips

- Export PNGs at 2x for crisp rendering on retina displays
- Compress with [tinypng.com](https://tinypng.com) before committing
- For GIFs, keep under ~5 MB; use [ezgif.com](https://ezgif.com) to optimize
- Match aspect ratios across screenshots so the README grid stays tidy
