Adding tasks

Tap the + button and type your task in plain language — Hindi, English, or Hinglish. Nudge will automatically extract the task name, subject, deadline, and priority.

Examples that work:

  • os assignment kal 5 baje urgent
  • maths test aaj subah 9 baje
  • submit physics lab friday
  • DBMS practical tomorrow 3pm
  • english essay parso by noon
Tip: The more context you give (subject + time + date), the more accurate the parsing. You can always edit any field after parsing.

Notifications & reminders

This is the most common issue on Android. Android aggressively kills background apps to save battery, which stops local notifications from firing. Follow the steps for your phone brand below.

All phones — do this first:

1

Go to Settings → Apps → Nudge → Battery

2

Select Unrestricted (not "Optimised")

3

Go back to Settings → Apps → Nudge → Notifications

4

Make sure Allow notifications is toggled on

Xiaomi / Redmi / POCO phones:

1

Settings → Apps → Manage apps → Nudge → Battery saver → No restrictions

2

Settings → Apps → Manage apps → Nudge → Autostart → Enable

3

Security app → Boost speed → Remove Nudge from the list

Samsung phones:

1

Settings → Battery → Background usage limits → Sleeping apps → Remove Nudge if listed

2

Settings → Apps → Nudge → Battery → Unrestricted

OnePlus / Realme / OPPO phones:

1

Settings → Battery → App battery optimisation → Nudge → Don't optimise

2

Settings → Apps → Nudge → Auto-launch → Enable

After changing battery settings, set a test reminder 2 minutes from now to confirm it fires before relying on Nudge for important deadlines.

When adding or editing a task, scroll down to the Reminders section. You can enable:

  • 1 day before — fires 24 hours before the deadline
  • 2 hours before — fires 2 hours before the deadline
  • At deadline — fires exactly at the deadline time
  • Custom — pick any date and time

You can enable multiple reminder types for the same task.

Nudge includes a boot receiver that re-schedules all your reminders automatically after a device restart. If reminders are not restoring after reboot:

1

Make sure Autostart is enabled for Nudge in your phone's settings (especially on Xiaomi, Realme, and OnePlus)

2

Open Nudge once after restarting your phone — this triggers the reminder restoration

3

If the issue persists, edit and re-save the affected task to reschedule its reminders

Voice input & OCR scan

1

Go to Settings → Apps → Nudge → Permissions and make sure Microphone is allowed

2

Make sure your device has a speech recognition engine installed. Go to Settings → General management → Language → On-device language processing (Samsung) or check that Google app is installed and up to date

3

Try speaking clearly in a quiet environment — background noise reduces accuracy significantly

4

If voice still fails, type your task instead — voice is optional and all features are available via text

Voice input uses Android's on-device speech recognition. Audio is never recorded or sent anywhere — processing happens entirely on your phone.

Tap the scan icon on the home screen. You can either pick an image from your gallery or take a photo. Nudge uses on-device ML Kit to extract text from the image, then automatically parses task names and deadlines from the extracted text.

Good inputs for OCR:

  • WhatsApp screenshots of assignment announcements
  • Photos of handwritten notes or timetables
  • Screenshots of college portals or notice boards
Note: OCR accuracy depends on image quality. Blurry, low-light, or very small text may not extract correctly. Re-scan with better lighting or type the text manually.
1

Make sure the image is well-lit and in focus — retake the photo in brighter conditions if needed

2

Crop the image to only the text area before scanning to improve accuracy

3

For screenshots (e.g. from WhatsApp), increase screenshot resolution in your camera settings

4

If OCR cannot extract the text, type or paste it manually into the task input — the parsing still works the same way

Data, privacy & account

Yes — because Nudge is fully offline with no cloud sync, all your data exists only on your device. Uninstalling the app permanently removes all tasks, streaks, XP, and documents.

There is currently no export or backup feature. If you plan to reinstall Nudge, note down any important deadlines before uninstalling.

You have three options:

  • Uninstall the app — removes everything permanently
  • Clear app data — go to Settings → Apps → Nudge → Storage → Clear Data. Resets the app to a fresh state without uninstalling
  • Delete individual tasks — swipe left on any task card

Since Nudge has no servers, there is no data on our end to delete. See our Data Deletion page for full details.

The parser uses pattern matching and works best when you include clear keywords. If it gets something wrong:

  • Tap any field in the review card to edit it directly before saving
  • Add more context to your input — e.g. write friday at 5pm instead of just friday
  • Use the subject keyword directly — e.g. maths, os, physics
If a particular phrase consistently parses incorrectly, let us know via email — we improve the parser with every update.
